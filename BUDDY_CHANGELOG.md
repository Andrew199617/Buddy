# Buddy changelog

## [0.11.4] - 2026-10-07

### Added

- Buddy's smiling conversation logo, light and dark wordmarks, and browser/app icons.
- A welcome screen and sign-in design with forest green, mint, and warm ivory surfaces.
- Buddy launchers that serve the frontend and backend from this checkout while keeping existing accounts and conversations.

### Changed

- Product names in browser titles, notifications, interface messages, settings, and translations now use Buddy.
- Sidebar, chat welcome, primary chat actions, splash screens, and installed-app metadata share Buddy's visual identity.
- Project documentation and in-app release notes now describe Buddy.
- Default icons use local Buddy assets.

### Fixed

- Stale default app names and legacy branding suffixes normalize to Buddy.
- Onboarding hides sign-in controls until Get started is selected.

Earlier upstream release history is preserved in CHANGELOG.md in the source repository.
